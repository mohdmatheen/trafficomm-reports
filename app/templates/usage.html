How each figure is defined
Request attempts
Every call this app made to Claude, including retries and failures.
Successful requests
Attempts that returned a usable answer. Retries of one logical request are linked to its first attempt.
Tasks
Distinct reporting tasks with at least one request by that employee in the period, whether or not the task is finished.
Tokens
Input (uncached), cache reads, cache writes and output, as returned by the provider for each request.
Awaiting provider cost
Successful requests completed after the provider’s latest data refresh, so their cost isn’t in the provider data yet.
Confirmed cost
Amounts the provider reports for this app’s mapped workspace or API keys. Never estimated from token counts here.
Since tracking began
From {{ d.tracking_started|local }}. Activity before that date wasn’t recorded. Provider cost data is available from 1 January 2026 and within the last 365 days.
